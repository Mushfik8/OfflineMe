# OfflineMe

A native Android app (Kotlin) that lets you control internet access on a per-app basis.

## Features (Phase 1)
- Pick specific installed apps to cut off from the internet entirely.
- Uses Android's VpnService purely as a local, on-device packet filter.
- Other apps bypass the VPN entirely and get the network completely untouched, at full native speed.
- Dark Theme interface built with Material 3.
